# TSB Atlas

An interactive field manual for **The Strongest Battlegrounds** (Saitama + universal combat). It is one self-contained web page with spacing and movement guides, a ping and hitbox lab, passive and pressure playbooks, player notes, gameplay videos, and a training program.

**Open it:** https://konecata21-maker.github.io/tsb-atlas/

## What's inside

| Section | What you get |
| --- | --- |
| Command center, framework, movement lab, neutral & reads | The decision loop, range rules, movement diagrams and HP-based tempo |
| Passive counterplay | Endlag bait, M1 catches and Khai dashes, with embedded clips |
| Pressure & spacing | Pressuring, flick camera/avatar bait, strafing, M1 trading, and player notes on spacing, HP, dash range and movement tricks |
| Saitama system | Move set, route families and a movement-to-move decision tree |
| Technique library | Searchable techniques with steps, failure points and drills |
| Ping & hitboxes, hitbox vision | Latency lab, reaction trainer, contact-map builder and the hitbox & ping playbook |
| Defense & terrain | Facing and block model, ping and block timing |
| Player study cards, matchup solver | Scouting template and counter-plans by opponent pattern |
| Gameplay | Playlist link and match footage |
| Sens, macros & rules | Top-player sensitivity/DPI list, downloadable Macro Gamer `.mgp` files, and the strike system |
| Training program, knowledge test, match notebook | 4-week plan, 21-question quiz, and a notebook that saves in your browser |

## Notes

- Numbers and timings from players are **player-reported** and can change with patches, FPS and ping. Test them in a private spar before relying on them.
- Ping and hitbox advice is coaching guidance. The real TSB hitboxes can't be read from outside the game.
- The page is a single file, `index.html`. To update it, replace that file and commit.
